# 最难的几组区分（Marr / 分层 / 信息判据）

给未来公开讲解页用的区别内核。Adam / Codex 建页；本页只收**混了就会写错**的词。不是术语大全，不是把 Marr 说成「就是我们那三层」。

配套：[`MARR-LAYERS-ISOMORPHISM-BRIEF.md`](./MARR-LAYERS-ISOMORPHISM-BRIEF.md)（论证）、[`MARR-LAYERS-OPEN-QS.md`](./MARR-LAYERS-OPEN-QS.md)（主人未点头 = 不做公开页）。

公开安全：无主机、无密钥、无私人运营细节。下列 Hub 编号只作已有出处，不新造。

---

## 1. 同构 ≠ 类比 ≠ 范畴错误

| 说法 | 意思 | 能说 / 不能说 |
|---|---|---|
| **同构 isomorphism** | 两边一一对应，结构两边都能走回去 | 不能说 Marr 三层 **就是** 描述 / 机制 / 本体 |
| **类比 analogy** | 有像的地方；账没还清 | 「都在禁止层间偷渡」——可以，且应先还类比债（变量、反例、增量预测） |
| **范畴错误 category error** | 把一种问题的答案当成另一种问题的答案 | 把「视觉系统在算什么」当成「宇宙是什么」 |

**可公开的一句：** 三套分层共享的是**纪律**（别拿这层的答案去填那层的空），不是同一张三行表。

---

## 2. Marr 的「计算层」≠「宇宙是一台计算机」

Marr 的 computational level 问的是：这个**已有功能的系统**在解决什么问题、为什么该这样解决。它是**问题说明书**，不是本体宣言。

- 视觉有「对观看者有用」这个消费者，所以计算层问得下去。
- 宇宙没有现成的外部消费者。问「宇宙在算什么题」等于把目的偷渡进本体。
- 英语 computational 很容易听成「世界在做计算」。那是另一主张，要单独爬信息判据的第 4 级，不能用 Marr 的形容词免单。

中文建议：**功能 / 问题层**，不要只写「计算层」。

---

## 3. 表征有三义，不可混用

| 标签 | 中文 | 住在哪一层 | 一句话 |
|---|---|---|---|
| **R1** | 账本表征 / 理论压缩 | 描述层 | 我们用来压现象的地图、不变量、模型 |
| **R2** | 系统内编码 | 机制层 = Marr 真正放 representation 的地方 | 算法改写的输入 / 输出编码 |
| **R3** | 本体即表征 | 本体层，且几乎总是偷渡 | 「世界本身是一幅表征」（表征给谁？） |

v0 把「表征」放在计算 / 描述格，那是 R1。Marr 书里的 representation 是 R2。R1 说成 R2、再说成 R3，是最常见的滑坡。

**可公开的一句：** 有一张好地图，不表示系统在用这张地图，更不表示世界就是这张地图。

未打 R1/R2/R3 的「表征」不是术语，只是日常词。

---

## 4. 实现 ≠ 本体；介质 ≠ 本体

| 词 | 问的是 | 不是 |
|---|---|---|
| **实现 implementation**（Marr 第 3 层） | 这条算法**落在什么东西上** | 世界底层是什么 |
| **介质 medium** | 规则在其中发生、会耗能、会失败的那摊东西 | 本体答案本身 |
| **本体 ontology** | 存在的是什么 | 一种实现关系 |

Marr 第 3 层**预设**已经有物理基底，然后问算法怎么实现。宇宙主线问的是那个基底本身——Marr 根本没问这句。

v0 表把「实现层 = 本体 + 介质」粘在一格，是整张表里最贵的错误。物理模型是**候选本体**；实现是**落点关系**。

**可公开的一句：** 「它跑在什么上」和「到底有什么」是两问。

口语里 物理 ≈ 实现 往往指同一 Marr 层，不要再拆成两层充数。

---

## 5. 读出 / 观察者 ≠ 第四本体层

Marr 需要观看者，因为视觉是**给谁看的**。宇宙主线不继承这个座位。

已经够用、且不升级成「第四种存在」的纪律：

- **观察者四分：** 物理相互作用 / 知觉压缩 / 认知解释 / 语言报告
- **机制四元组：** 触发、状态参量、转移、**读出**。缺一项就还是比喻
- **先排除读出偷换，再谈机制与本体。** 读出函数可以整段改写成更大的状态；单凭读数对不上「这是读出而不是隐状态」

若一定要第四样，那是**认识 / 账本层**（这话是怎么被知道、被说出来的），不是第四种存在。意识、视觉、能动是 Marr 的老家；它们是子域，定不了宇宙主线有几层。

**可公开的一句：** 读出是机制里的一个坐标，不是世界多出来的一层。

---

## 6. 四层信息判据是另一根轴

专门审「X 是信息 / 是代码 / 是计算」这种话，**不要**折进 Marr，也**不要**当成 Hub 三层的第四层。

1. **可描述** — 能写下一种表示
2. **可压缩的生成律** — 更短的规则能再生现象
3. **在介质里因果执行** — 规则真的在某物中发生，有代价、有失败
4. **信息即本体** — 主张存在的就是信息（或代码、或计算）

「现实可编码」只买到第 1 级。它不自动选出宇宙的规律，更不证明「信息制造了物质」。新实体（模拟器、频率库、业力数据库……）要付解释增益：更压缩、或更统一、或能做出可判别的预测。

已发表的「从可编码到物理可能性」把 **可编码 / 可压缩 / 可执行 / 物理实现** 分成四个前提。那第四项仍是**介质 / 实现**，不是本表第 4 级「信息即本体」。两套四项不要贴成一张表。

层间跳级的典型假动作：可描述 ⇒ 是信息 ⇒ 是代码 ⇒ 宇宙是电脑 ⇒ 所以本体就是信息。每一箭头都要单独买票。

---

## 7. 主线是宇宙本质；Marr 管有功能的系统

- **主线：** 宇宙根本上是什么。意识、自我边界、滞回、数字主体工程是子域，不是替身。
- **Marr 的老家：** 视觉、知觉、智能、能动——已经是「为某消费者工作」的系统。
- 把 Marr 整套上迁到宇宙，会把「功能 / 消费者」一起偷渡上去。

工程层的词（状态、环、信道、投射、表征）**有用**。把它们直接当成胜义 / 终极本体答案，是语法自己在越权。

---

## 8. 「层间偷渡」一句话版

不是三张名字贴同一张幻灯片。

- 拿描述当机制：长得像，四元组却不齐。
- 拿机制当本体：有动力学，就说世界*是*这套动力学。
- 拿实现当本体：物理词汇冒充存在答案。
- 拿 Marr 的「计算」当「世界在计算」。
- 拿「需要读出」当「存在依赖观察者」。

**可公开的收束：** 分层是为了让问题待在自己的座位上。座位对齐了，并不等于世界的结构被证明成三层。
